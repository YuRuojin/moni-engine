# 引擎与项目工具

中文 | [English](README_en.md)

`tools/` 负责引擎安装、Hub/启动器、项目创建与升级、插件包管理和开发命令行。它管理引擎外部的安装与仓库，不是玩家运行时的一部分。

## 职责边界

- 引擎管理：下载、安装、校验、选择、卸载和保留多个引擎版本。
- Hub 与项目工具：创建、打开、迁移项目，选择引擎版本和命名 profile。
- 插件与组合管理：注册表查询、依赖图解析、锁文件、安装、更新、回滚和删除。
- Profile 工具：选择 bundles、应用有序补丁、导出和检查最终有效插件树。
- 发布元数据：来源、签名、哈希、第三方许可和兼容目标。
- 自动化 CLI：为开发者和 agent 提供与界面等价的插件、服务和 profile 操作及结构化错误。

命名 profile 与 bundles 属于 [`profiles/`](../profiles/README.md)，游戏包导出属于 [`plugins/platforms/`](../plugins/platforms/README.md)，插件接口和权限声明属于 [`sdk/`](../sdk/README.md)，编辑器内界面属于 [`plugins/editor/`](../plugins/editor/README.md)。

## 依赖与信任

项目直接依赖和插件间接依赖共同形成确定版本图。锁文件保证重复安装；更新必须显示版本与权限变化。下载内容需要校验来源和完整性，原生代码与脚本权限不能因传递依赖静默扩大。

## 性能与稳定性

- Hub 和包管理不进入玩家构建，也不应常驻占用游戏运行资源。
- 安装与更新使用临时目录和原子切换，失败可回滚，不能破坏现有项目或引擎版本。
- 所有操作支持取消、结构化错误和可复现日志；凭据不得进入仓库、命令输出或日志。
- 注册表不可用时保留已安装版本和锁文件的离线工作能力。

## 当前限制

已实现 `new`、`run`、`doctor` 和项目感知的 `profile dump`，支持模板复制、Git 初始化、锁文件生成/校验/更新/备份/回滚、权限差异接受和项目 TypeScript 构建。Hub、引擎安装器、插件注册表客户端、外部依赖安装和通用项目升级工具尚未实现。
