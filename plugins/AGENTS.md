# AGENTS.md — 官方插件

- 修改插件前阅读 `plugins/README.md` 和所属分类 README；具体实现出现后，再阅读该插件自己的 README。
- 一个插件只选择一个主要功能分类，通过服务定义使用其他分类的能力。不要把渲染、资源、编辑器或打包逻辑混在同一个实现模块中。
- 可替换能力同时明确服务定义、提供方和消费者；注册必须可撤销。运行环境组合放入 `profiles/`，公共接口放入 `sdk/`，不修改入口制造特权路径。
- 这里只放有真实实现的官方插件，不创建空壳实现目录。第三方通用插件和游戏专属插件放在各自外部仓库。
- 当前优先 Rust 静态注册；没有正式接口前，不引入动态库 ABI、全局单例或不可撤销的注册。
- 新实现必须说明启停与释放、错误传播、可选依赖、目标平台和性能成本。未启用插件不得进入玩家热路径。
- 每个具体插件同步维护 `README.md` 与 `README_en.md`，并在所属分类 README 添加一行索引。
