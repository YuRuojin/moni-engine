# 资源插件

中文 | [English](README_en.md)

`assets/` 负责从外部文件生成引擎可复现使用的资源，包括格式探测、读取、验证、转换、导入元数据、缓存和资源依赖。这里的“控件”主要是文件类型处理器，不是编辑器界面控件。

## 职责边界

- 格式提供方：模型、纹理、音频、字体、场景等明确扩展名或内容格式。
- 导入器：把源文件转换为规范中间数据，报告可定位的错误。
- 资源数据库：稳定资源标识、源文件哈希、导入设置和依赖关系。
- 缓存：按源内容、导入器版本、设置和目标平台失效的转换结果。
- 运行时加载：虚拟资源路径、共享引用、异步加载、预加载、取消、卸载和热重载。
- 流式与发布读取：大型资源分块加载，以及导出后压缩包和 cooked 资源的统一访问。
- 构建输入：向 [`platforms/`](../platforms/README.md) 提供明确的资源清单和依赖。

GPU 上传与材质使用属于 [`rendering/`](../rendering/README.md)，资源浏览和导入设置界面属于 [`editor/`](../editor/README.md)。

## 首批官方能力

当前静态 FBX 导入器位于 `src/fbx.rs`，支持几何三角化、法线、节点变换、材质基础色、坐标/单位转换和按最大边归一化。后续将其抽为正式格式提供方，并统一资源标识、导入结果、纹理与其他模型格式。

## 性能与稳定性

- 导入属于开发或构建路径，不得在渲染热路径同步读取或转换文件。
- 大型文件使用流式读取、明确大小上限和取消机制，避免整个文件无界进入内存。
- 缓存键必须包含影响结果的内容和版本；并发导入不得写出半完成缓存。
- 不可信或复杂解析器优先在隔离进程中运行，解析失败不能崩溃编辑器或玩家运行时。
- 游戏包只包含经过验证的依赖资源，不依赖开发机绝对路径。

## 当前实现

- [`fbx/`](fbx/README.md)：FBX 几何、法线、节点变换和材质基础色。
- [`runtime/`](runtime/README.md)：有界异步加载、共享引用、取消、超时和缓存。
- [`cooked/`](cooked/README.md)：`.mnec` 静态几何读写与 FBX 转换。

初始化通过同一 worker 预加载，运行中新增模型由 `poll` 非阻塞接收。当前没有资源数据库、纹理、动画、虚拟资源路径、持久导入缓存、依赖图或完整资源包；cooked 文件仍需逐个读取。
