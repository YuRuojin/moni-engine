# 异步资源运行时

中文 | [English](README_en.md)

`mod.rs` 提供有界异步资源加载，使用一个 `moni-asset-loader` worker 和最多 64 项的请求/响应队列。worker 只读取 FBX 或 cooked mesh，不访问世界或 GPU。

## 生命周期

- `load`：去重并提交非阻塞加载。
- `preload`：初始化阶段等待同一 worker 完成，超时或错误会失败。
- `poll`：渲染线程非阻塞接收结果，不等待文件 I/O。
- `set_references`：按场景资源引用更新共享生命周期。
- `shutdown`：取消待处理任务、通知 worker、等待退出并清空缓存。

单个请求默认超时 10 秒。超时会取消结果提交并记录错误；解析器内部不能被强制中断，因此 worker 关闭时需要等待当前解析调用返回。

队列满、解析失败、超时和运行时关闭都有明确错误。新模型在加载完成后进入 GPU 缓存，不在渲染帧中同步解析。需要崩溃隔离的导入任务可以使用 `cook --isolate` 的独立进程，但该模式不是安全沙箱。
