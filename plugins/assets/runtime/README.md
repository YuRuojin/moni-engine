# 异步资源运行时

中文 | [English](README_en.md)

`mod.rs` 提供有界异步资源加载，使用一个 `moni-asset-loader` worker 和最多 64 项的请求/响应队列。worker 只读取 FBX 或 cooked mesh，不访问世界或 GPU。

## 生命周期

- `load`：去重并提交非阻塞加载。
- `preload`：初始化阶段等待同一 worker 完成，超时或错误会失败。
- `poll`：渲染线程非阻塞接收结果，不等待文件 I/O。
- `set_references`：按场景资源引用更新共享生命周期。
- `set_aliases`：安装 `res://<alias>` 虚拟路径表（来自场景 `extensions.res`）。
- `handle`：返回带修订号的缓存句柄；修订号在每次成功加载后递增。
- `shutdown`：取消待处理任务、通知 worker、等待退出并清空缓存。

## 虚拟资源路径

`res://<alias>` 在 `load` 时解析为 workspace 相对物理路径，worker 收到的仍是物理路径；缓存、错误与引用表始终以别名（即原始字符串）为键，因此别名就是资源的稳定标识。未声明的别名会得到明确错误，不会静默回退。

## 热重载

热重载默认关闭，由 `client --hot-reload` 或 `editor --hot-reload` 显式开启；关闭时不产生任何每帧 stat 成本。开启后 `poll` 对已引用、已缓存资源比较 mtime+size 指纹：源文件变化即从有界队列重新排队加载，渲染侧继续使用上一修订号，新版本到达后按修订号差异重建 GPU 缓冲。重载解析失败保留上一版本渲染，并通过一次性 stderr 诊断提示；指纹使用 mtime+size 而非内容哈希，开发者手动改回相同内容不会触发重载。

单个请求默认超时 10 秒。超时会取消结果提交并记录错误；解析器内部不能被强制中断，因此 worker 关闭时需要等待当前解析调用返回。

队列满、解析失败、超时和运行时关闭都有明确错误。新模型在加载完成后进入 GPU 缓存，不在渲染帧中同步解析。需要崩溃隔离的导入任务可以使用 `cook --isolate` 的独立进程，但该模式不是安全沙箱。
