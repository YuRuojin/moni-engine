# 可视化编辑器插件

中文 | [English](README_en.md)

`editor/` 负责可视化开发工具和项目操作，包括编辑器外壳、场景层级、检查器、视口、变换控件、资源浏览、脚本面板和插件 UI。编辑器通过公开命令与查询接口操作游戏工程，不直接改写引擎内部状态。

## 职责边界

- 编辑器外壳：窗口、布局、工作区、菜单和项目选择。
- 场景工具：层级、选择、检查器、视口、相机和变换控件。
- 可扩展控件：属性编辑器、资源选择器、图表和插件面板。
- 项目界面：展示创建、打开、保存和构建操作，通过 [`tools/`](../../tools/README.md) 与平台服务执行，不直接实现安装、依赖解析或导出器。

资源解析属于 [`assets/`](../assets/README.md)，渲染画面属于 [`rendering/`](../rendering/README.md)，安装包生成属于 [`platforms/`](../platforms/README.md)。

## 首批官方能力

先建立独立项目模型和只读场景预览，再实现层级、检查器与变换编辑。编辑器控件需要有稳定标识、类型化属性和命令映射，使 agent 可以执行与界面等价的操作。

## 性能与稳定性

- 编辑器是开发工具，默认不得进入玩家构建；未安装编辑器时运行时不承担其依赖和更新成本。
- 大场景层级、资源列表和日志需要虚拟化、分页或明确上限，不能随工程增长无界占用内存。
- 编辑操作使用可撤销命令，并在保存时验证数据；失败不能留下半个场景状态。
- 导入、打包和分析等长任务在后台执行，提供进度、取消和明确错误，不阻塞视口。
- 插件面板卸载时必须释放订阅、定时器和文件监听。

## 当前限制

当前有 `editor` 命令的只读场景查看器，可加载 `.mnsc`、显示实体层级、模型资源、灯光和性能覆盖层，并支持相机移动与缩放；不执行脚本或写回文件。完整属性编辑、项目创建器、控件注册和撤销系统尚未实现。
