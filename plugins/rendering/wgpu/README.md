# wgpu 渲染插件

中文 | [English](README_en.md)

`mod.rs` 与三个 WGSL 文件实现当前 2D/3D/阴影渲染。该目录是渲染提供方的实际代码位置，通过 `core.render` 静态注册到宿主。

## 当前能力

- 2D 精灵和编辑器 overlay。
- 内置网格与 FBX/cooked mesh。
- 正交/透视相机、深度测试、方向光、最多 8 个点光源。
- 基础色、金属度、粗糙度材质。
- 1024 方向光阴影与 3x3 PCF。
- FBX GPU 顶点缓存、每实体模型矩阵、包围球视锥剔除。
- 基准模式 GPU 时间戳。
- 静态场景的一次性 RGBA golden 捕获和像素/元数据一致性检查。

资源解析由 `plugins/assets/` 负责。GPU 资源只在渲染线程创建、使用和释放。

## 限制

没有动态 ABI、纹理、动画、级联阴影、后处理、实例化或跨平台 golden 渲染。GPU 时间戳需要硬件支持，采样只用于基准和只读查看器。
